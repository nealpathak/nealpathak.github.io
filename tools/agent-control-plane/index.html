Agent Control Plane

Ten agents run a captive's claims reporting, certificates, matter intake and board pack. The interesting part is not the agents. It is the layer that decides what each may do and what data it may touch, sequences them, holds anything bound for the outside world until a person signs, and can prove all of it afterwards. This is that layer, on a synthetic fleet, with the switches live.

Kill switches

Today's run

Sequence and status

Agents run in dependency order. An exception hold on the claim listing stops everything that reads it; an external gate holds only the delivery, so internal reporting still refreshes. A thrown switch idles the agent and everything downstream, each with its documented fallback.

Impact

What a thrown switch costs

Every agent has a manual fallback with an owner and an hours estimate. Switching one off idles it and everything downstream; the number is the people-hours per day it takes to keep the business running by hand until it is back.

Authorisation

What each agent may touch

The data authorisation matrix is the artefact a committee approves and an examiner asks for. Reads are enforced at run time; writes are checked against the destination, and claimant personal data can never be written to anything outside the company regardless of what an agent asks for.

Controls

Coverage by agent

Seven controls every production agent must carry. Coverage is computed, not asserted: an agent that fails a control is not eligible for production and stays in pilot until it passes.

Audit

The run log an examiner would read

One row per action: who, what, on which data, and the decision the policy engine made. Denials and holds are the rows that matter; the rest is evidence that the ordinary case is ordinary.

Method

Assumptions on the surface

Fleet
Ten agents modelled on the shape of a captive's daily operation. Owners are roles. Schedules, data scopes, gates and fallbacks are illustrative but the relationships between them are the point.
Policy engine
A read is allowed if the data class is in the agent's authorised set. A write is allowed if the destination is in the agent's set, the payload contains only classes the agent may read, and no restricted class goes to an external destination. Privileged material needs a gate before any external destination.
Gates
Three kinds. An exception gate holds the release of an internal artefact and blocks dependants. An external gate holds delivery outside the company. An attorney gate queues recommendations for counsel.
Run simulation
Deterministic for a given day, set of switches and injected event. Durations are seeded noise; decisions are not.
Tests
node tools/agent-control-plane/selftest.mjs checks dependency ordering, impact arithmetic, every authorisation rule, coverage detection, and each injected event's expected outcome.
